# Project 1 - ExploreWithLuxe

This project is a static multi-page travel website created to showcase a luxury travel company called ExploreWithLuxe. The website is designed to help users explore the brand, learn about its services, and contact the company for travel inquiries.

## Purpose of the Project

The goal of Project 1 is to demonstrate foundational web development skills using HTML, CSS, and Bootstrap. It introduces the structure and design of a simple website with:

- a home page
- an about page
- a contact page
- a shared navigation bar
- a consistent visual theme

## Functionalities

### 1. Home Page
The home page introduces the brand and highlights the travel experiences offered by ExploreWithLuxe. It includes:

- a welcoming headline
- a short brand description
- a large travel image
- content describing local and international travel experiences
- a visual layout intended to attract potential travelers

### 2. About Page
The about page provides background information about the company, including:

- the business purpose
- the focus on personalized luxury travel planning
- details about local expertise and tailored itineraries
- a visual banner image to support the brand identity

### 3. Contact Page
The contact page allows users to get in touch with the company. It includes:

- a contact section with company messaging and privacy information
- a contact form with fields for name, email, phone number, and message
- a submit button for sending customer inquiries
- a responsive layout that fits the overall website design

### 4. Navigation System
Each page includes a navigation bar that connects the website together. Users can move between:

- Home
- About
- Contact

This creates a simple multi-page browsing experience without the need for a backend.

### 5. Styling and Layout
The website uses:

- Bootstrap for layout and responsive design
- custom CSS for consistent colors, spacing, form styling, and page structure
- centered content blocks and image formatting for a polished look

### 6. Responsive Design
The layout is built to adapt to different screen sizes, making the website accessible on desktop and smaller devices.

## Files Included

- index.html - home page
- about.html - company information page
- contact.html - contact form page
- styles.css - shared styling for the website
- images/ - media files used throughout the site

## Technologies Used

- HTML
- CSS
- Bootstrap 5

## Summary

Project 1 is a simple but complete static website that demonstrates how a travel business can present itself online. It combines branding, informational content, user interaction through a contact form, and consistent styling to create a professional web presence.
